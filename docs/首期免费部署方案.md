# 首期免费部署方案

> 文档状态：免费信令基线；TURN 条目已于 2026-08-01 更新为用户已订阅的 Worker Secret 配置
> 版本：v1.3
> 适用范围：单用户、当前 macOS、iOS/Android 手机外网上传、首期三类 Vlog

## 1. 结论

首期采用“本机处理 + Cloudflare 免费层信令”的部署方案：不租 VPS、不部署云端数据库、不部署云端对象存储，也不将素材、成片、声音样本或剪映工程上传云端。

| 部分 | 部署位置 | 首期方案 | 成本边界 |
| --- | --- | --- | --- |
| Web、Server、SQLite、素材、AI、剪映 Runner | 用户 Mac | 本机安装包启动本地服务，浏览器访问本机 Web | 无云服务器成本 |
| WSS 信令与在线状态 | Cloudflare Workers + Durable Object | 使用 `*.workers.dev`，一个本机节点一个会话对象 | Workers/DO 免费层内运行；超出免费配额时停止新配对/会话并提示用户；**不作为媒体中继** |
| WebRTC NAT 探测/中继 | STUN 优先 + Cloudflare TURN | 直连优先；本机经 HMAC 请求 Worker 生成会话级短期 TURN 凭据 | TURN 流量按 Cloudflare 实际资费计费；长期值只保存在 Worker Secret |
| 公开域名 | 不部署 | 首期使用 `*.workers.dev` | 不购买自定义域名 |
| 手机安装 | 用户自己的设备 | iOS 使用 Xcode 本机安装；Android 使用本地签名 APK 安装 | 不上 App Store / Google Play，不产生商店发布费用 |

## 2. 云端最小职责

Cloudflare Workers + Durable Object 只处理：

- 一次性配对挑战和已绑定设备的会话路由；
- 本机节点在线/离线心跳；
- WebRTC Offer、Answer、ICE Candidate 的 WSS 转发；
- 上传令牌申请的转发与撤销通知。

禁止处理：素材分块、项目/素材目录、SQLite 数据、声音样本、生成结果、剪映截图、成片下载和任何素材持久化。

每个本机节点使用不可枚举的 Durable Object 路由；长连接必须启用 WebSocket Hibernation。信令只保留最小会话路由，配对、ICE 和令牌请求均设置速率限制、最大报文大小和在线状态 TTL；不得把项目/分类/文件摘要作为云端持久业务记录。

云端并非“没有任何数据”：Cloudflare 仍会按其服务规则处理 WSS 内容、IP/端口、会话时间、ICE 候选和 TURN 流量计费元数据。首次配对及启用中继前，产品必须展示该最小数据清单、服务商保留规则和本机的撤销入口。

Cloudflare Realtime TURN 可能产生费用，而与 SFU 的免费组合会让媒体经过云端，均不符合固定边界。已订阅账户把长期 TURN Key/API Token 仅写入 Worker Secret；本机以已有信令 HMAC 请求会话级短期 ICE 凭据，手机只接收短期值。Mac 离线时，手机保存本地上传队列，待 Mac 在线后续传。

## 3. 运行与配额策略

1. 本机 Server 持续向信令服务发送在线心跳；Mac 休眠、断网或服务退出后，节点即为离线。
2. 手机先使用 STUN 候选；本机为每个上传会话经 Worker 请求短期 TURN 凭据，并同时配置给 Mac 和手机。Worker Secret 缺失或签发失败时准确返回可恢复失败。
3. 不自动购买、自动升级或使用 SFU 绕路；TURN 是否启用和承担资费由用户的 Cloudflare Worker Secret 配置决定。
4. Workers 或 Durable Object 免费配额不可用时，信令进入可解释阻塞状态；本机素材、任务和已提交上传不受影响。
5. 服务商改变价格或可用性时，Provider Adapter 默认视为不可用；不得静默转为付费。

## 4. 手机安装边界

- iOS：首期只服务用户本人的设备，以 Xcode 从 Mac 本机安装；免费个人签名可能需要周期性重新签名。未来若需要稳定远程分发或 TestFlight，再单独启用 Apple Developer Program。
- Android：首期由本机生成并签名 APK，用户在自己的 Android 手机安装；未来若上架 Google Play，再单独办理 Play 开发者账号。
- 首期不建设应用商店发布、自动更新分发或多用户设备运营能力。

## 5. 部署顺序

1. 在 Mac 安装并启动本机 Server、SQLite、素材根目录和本地 Web。
2. 创建 Cloudflare 账户，部署 Workers + Durable Object 信令服务，使用 `workers.dev` 地址。
3. 将 TURN Key ID 与 API Token 设置为 Cloudflare Worker Secret，验证长期 Token 不会下发给本机或 H5。
4. 使用本机 Web 生成二维码，在 iOS/Android 设备完成一次性配对。
5. 依次验证直连上传、已配置 TURN 的受限网络上传、Mac 离线排队和设备撤销。
6. 通过《本机入库可靠性 PoC 验收清单》后，再进入剪映 GUI 自动化 PoC。

## 6. 非首期范围

- 付费 VPS、自建 coturn、云端素材备份、云端数据库和对象存储；
- 自定义域名、团队用户、远程 App 分发和应用商店发布；
- 在免费额度耗尽后自动购买或自动升级任何云服务。
